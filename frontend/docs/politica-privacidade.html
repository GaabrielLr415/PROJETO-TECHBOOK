TECHBOOK

Política de Privacidade
Versão: 1.0
Atualização: 24/05/2026

Resumo: a TECHBOOK utiliza dados pessoais apenas para cadastro, reserva, empréstimo, devolução, comunicação com o cliente e controle do acervo da biblioteca.

1. Objetivo

Esta política explica como o sistema TECHBOOK coleta, utiliza, organiza e protege os dados dos usuários cadastrados na plataforma.

O documento foi criado para demonstrar transparência no tratamento das informações e apoiar a conformidade com boas práticas de privacidade e proteção de dados.

2. Dados Coletados

Para permitir o uso do sistema, a TECHBOOK pode tratar os seguintes dados:

  • nome completo;
  • CPF;
  • e-mail;
  • telefone;
  • senha de acesso;
  • histórico de reservas, empréstimos, devoluções, atrasos e pendências.

3. Finalidade do Uso

Os dados são utilizados para:

  • identificar o cliente no sistema;
  • permitir login e acesso à área do cliente;
  • realizar reservas de livros;
  • registrar retiradas, empréstimos e devoluções;
  • acompanhar atrasos, extravios e bloqueios temporários;
  • facilitar contato administrativo quando houver pendência;
  • gerar histórico individual de movimentações do usuário.

4. Compartilhamento

A TECHBOOK não comercializa dados pessoais. As informações ficam restritas ao funcionamento do sistema e ao acesso administrativo necessário para controle do acervo.

5. Segurança

O projeto adota medidas básicas de proteção, como controle de acesso, validação de dados e organização das informações no banco de dados.

Em uma implantação real, recomenda-se reforçar a segurança com autenticação administrativa individual, criptografia adequada, controle de permissões, auditoria de ações e rotinas de backup.

6. Retenção dos Dados

Os dados são mantidos enquanto o cadastro do cliente estiver ativo ou enquanto forem necessários para controle do histórico de reservas, empréstimos, devoluções e pendências.

7. Direitos do Usuário

O usuário pode solicitar acesso, correção ou atualização dos seus dados cadastrais. Também pode solicitar informações sobre seu histórico de movimentações na biblioteca.

8. Responsabilidade do Usuário

O usuário deve fornecer informações corretas, manter seus dados atualizados e preservar a confidencialidade da senha de acesso.

9. Melhorias Futuras

Para uso em larga escala, a TECHBOOK poderá evoluir com recursos adicionais de privacidade, como logs de auditoria, relatórios de acesso, exportação de dados do cliente e gestão formal de consentimento.

10. Contato

Dúvidas sobre esta política podem ser encaminhadas pelo canal de suporte disponível no site da TECHBOOK.
